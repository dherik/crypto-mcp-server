# crypto-mcp-server

![TypeScript](https://img.shields.io/badge/TypeScript-5.8-blue) ![Node](https://img.shields.io/badge/Node-18+-green) ![License: MIT](https://img.shields.io/badge/License-MIT-yellow)

An MCP (Model Context Protocol) server that connects AI agents (GitHub Copilot, OpenCode, Claude, etc.) to live crypto market data via the [CoinGecko API](https://www.coingecko.com/en/api). No API key required.

## What it does

Exposes 5 tools for real-time crypto questions:

| Tool | Description |
|------|-------------|
| `get_crypto_price` | Price, market cap, volume, 24h change for any coin |
| `get_top_coins` | Top N coins ranked by market cap |
| `compare_coins` | Side-by-side comparison of two coins |
| `get_market_overview` | Global market cap, BTC dominance, active coins |
| `get_coin_history` | Open/close/high/low over N days |

### Example prompts for your AI agent

- *"How is ETH doing today?"*
- *"Compare Bitcoin and Solana"*
- *"What are the top 5 coins right now?"*
- *"Give me a market overview"*
- *"What has BTC done in the last 30 days?"*

## Setup

### 1. Install dependencies and build

```bash
npm install
npm run build
```

### 2. Test with MCP Inspector (recommended before connecting)

```bash
npm run inspector
```

Open http://127.0.0.1:6274 in your browser. Select **stdio** as the transport, point it at `build/index.js`, and try out each tool interactively.

### 3. Connect to GitHub Copilot (VS Code)

Create a `.vscode/mcp.json` file in your project root:

```json
{
  "servers": {
    "crypto": {
      "command": "node",
      "args": ["/ABSOLUTE/PATH/TO/crypto-mcp/build/index.js"]
    }
  }
}
```

Open Copilot Chat, select **Agent** mode, and the crypto tools will be available.

### 4. Connect to OpenCode

Add the MCP server to your `opencode.json` config:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "crypto": {
      "type": "local",
      "command": ["node", "/ABSOLUTE/PATH/TO/crypto-mcp/build/index.js"],
      "enabled": true
    }
  }
}
```

The crypto tools are automatically available in your prompts. You can reference them with `use the crypto tool`.

## Extending this server

To add a new tool, copy one of the `server.registerTool(...)` blocks in `src/index.ts` and:
1. Give it a unique name
2. Write a clear `description` (the AI agent uses this to decide when to call the tool)
3. Define the input schema with Zod
4. Call the CoinGecko API and return `{ content: [{ type: "text", text: ... }] }`

CoinGecko API docs: https://docs.coingecko.com/reference/introduction

## Notes

- This server uses the **free CoinGecko API** (no key needed, 30 req/min limit). Rate limit errors (HTTP 429) are caught and surfaced as friendly messages.
- `console.error()` is used intentionally for debug logs — `console.log()` would corrupt the stdio JSON-RPC messages
- All tools are read-only; this server never writes data or makes transactions
- Coin IDs are sanitized to prevent injection in API URLs
